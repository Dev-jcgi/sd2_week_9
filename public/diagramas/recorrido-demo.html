¿Qué recorrido muestra la demo del Delivery System?

Long image

A

Answer

Un pedido de punta a punta contado como la historia de un cliente: entra, elige productos, paga, el comercio lo prepara y un repartidor lo entrega con su código. Así se ven los cinco módulos trabajando juntos en menos de cinco minutos.

  1. Cada paso usa un contrato de core-module: UserService, CatalogService, OrderService y PaymentService.
  2. El código de confirmación son los últimos 4 caracteres del id del pedido (decisión D-02).
  3. Pagos cobra con el último método de pago registrado (decisión D-04).

¿Qué módulo entra en cada paso?

Diagram structure
  • Cliente cli
  • Catálogo cat
  • Pedidos ord
  • Pagos pay
  • Entregas del
  • cli → cat · ver comercios y productos disponibles
  • cli → ord · agregar al carrito y crear pedido
  • ord → cat · reservar stock (D-09)
  • ord → pay · cobrar con el último método (D-04)
  • pay → ord · pago aprobado
  • del → ord · repartidor toma el pedido
  • del → cli · pide el código (D-02)
  • del → ord · entregado
  1. Elegir ↗

    El cliente ve comercios habilitados y productos con stock.

  2. Pedir ↗

    Pedidos crea el pedido y reserva el stock en catálogo.

  3. Pagar ↗

    Pagos cobra con el último método registrado.

  4. Entregar ↗

    El repartidor avanza los estados y confirma con el código.
